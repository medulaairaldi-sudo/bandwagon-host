# 搬瓦工购买教程：从套餐选择到服务器管理

第一次购买 VPS，最容易遇到的问题不是如何点击下单，而是不知道配置、线路和付款周期之间有什么区别。这篇指南以 BandwagonHost（搬瓦工）的套餐资料为基础，梳理选购前的比较方法、注册和付款步骤，以及拿到服务器后如何找到管理入口。

套餐价格和条件可能变化，表格中的数字是参考资料所列价格，并非实时报价。下单时应以具体套餐页面和购物车显示的配置、周期及金额为准。

## 搬瓦工是什么，适合哪些需求

BandwagonHost 是加拿大 IT7 Networks 旗下的 VPS 服务商。VPS 可以理解为在服务器上分配给用户使用的虚拟服务器：选择套餐时，需要同时考虑计算资源、存储空间、流量和网络条件，而不只是比较价格。服务商提供 KiwiVM 控制面板，可在网页中进行开关机、重装系统和查看资源等管理操作。

如果想学习 Linux，或者为个人网站寻找服务器，VPS 提供了一个可自行管理系统的环境。与只使用现成应用不同，购买者还需要关注账户信息、服务器登录信息和数据管理。对于初学者，先明确自己准备运行什么、是否愿意维护系统，再选择资源和付款周期，通常比直接追求最高配置更有帮助。

购买前准备一个能够正常收信的邮箱和可用的支付方式。订单通知和服务器信息会发送到邮箱，因此下单后也要保留对该邮箱的访问。若需要多人共同管理，先考虑如何安全地保存账户和服务器登录信息，避免将密码随意转发。

## 搬瓦工套餐怎么选：先看资源，再看线路

### 配置和计费周期

套餐中的 **vCPU** 是分配给虚拟服务器的处理器资源；**内存**影响程序运行时可用的空间；**SSD 容量**则决定系统、应用和文件的存储余量。比较时不能只看其中一项：例如网站文件不多，但运行的程序需要更多内存时，单纯增加硬盘并不能解决内存不足。表中的普通 KVM 套餐标注 SSD RAID-10，CN2 套餐标注 SSD，应分别按页面所列配置核对。

**月流量**与带宽不是同一个指标。前者是一定周期内的数据传输额度，后者是套餐所标示的连接带宽。标称 1 Gbps 或 2.5 Gbps 不能直接当作实际下载速度；访问路径、网络环境等都会影响实际表现。预计会传输较多文件或有较多访问的用户，应同时留意月流量额度，而不是只看带宽数字。

付款周期也会影响一次需要支付的金额。表中既有年付的普通 KVM，也有月付、季付及部分提供年付价格的方案。比较时应将金额和周期一起看：月价不能直接和年价比较，季付与年付也不能只看单次账单。先确定愿意一次投入多少，再核对所选周期与页面上的应付金额。

### 线路和机房

参考资料将普通 KVM 与 CN2 GIA-E 区分为不同线路选择：前者使用普通线路，后者强调三网回程优化。香港 CN2 GIA 则是表中单独列出的香港方案。线路名称、机房位置和资源配置都可能影响选择，但不能仅凭名称推断每位用户的实际速度或延迟。

选择时先想清楚主要访问人群在哪里、对网络路径有何要求，以及预算能否覆盖相应套餐。若重点是练习系统操作，资源和费用可能更容易成为筛选起点；若访问线路是主要考虑因素，则应进一步查看套餐页面提供的机房与线路信息。机房是否可选、能否迁移，应按具体套餐的当前条件确认，不应把某一方案的条件套用到全部产品。

## 注册、下单与支付宝付款

### 1. 进入套餐并加入购物车

可从[套餐总览入口](https://bwh81.net/aff.php?aff=59244)进入，或使用上表对应套餐链接。在页面上确认产品名称、资源、机房选项和计费周期，再点击 **Order Now** 或 **Add to Cart**。加入购物车后，先检查所选项目是否与预期一致；需要调整时应在付款前完成。

如果主域名 bandwagonhost.com 无法访问，参考资料提供的入口使用镜像域名 bwh81.net。进入后仍需核对浏览器地址和订单内容，不要仅凭搜索结果或页面外观判断正在购买的产品。

### 2. 登录或填写注册信息

在购物车结算过程中，已有账户可以登录，新用户可以直接填写资料创建账户。姓名和地址可使用拼音；邮箱应填写经常使用且能够收信的地址。资料还包括城市、省份、电话号码和密码，公司名称可不填。

**Country** 应选择实际所在的国家或地区，其他联系资料也应真实填写。参考资料提示，使用代理注册可能触发欺诈订单检查；填写前留意当前网络环境。完成后可按页面提示点击 **Update** 保存，再检查邮箱、国家和联系电话是否有误。账户密码建议使用字母、数字和符号的组合，并妥善保管。

### 3. 验证优惠码并核对金额

参考资料列出优惠码 `NODESEEK2026`，称其为 6.77% 的循环折扣。可在结算页的 **Promotional Code** 输入框填写后点击 **Validate Code**，查看页面是否接受以及实际显示的折扣。优惠码可能过期或有适用条件，不应在验证之前把折扣算作确定优惠，也不要假定续费时仍会适用。

付款前逐项检查套餐名称、周期、原价、折扣和最终应付金额。优惠码无效时，可以按页面显示的金额重新判断是否继续购买；确认无误后点击 **Checkout**，按页面提示进入支付环节。

### 4. 选择支付方式

参考资料列出的支付方式包括支付宝、PayPal、信用卡和银联。使用支付宝时，选择 **Alipay**，点击 **Complete Order**，按跳转页面提示扫码付款。若选择其他方式，则按相应付款页面完成操作。支付选项和最终金额应以结算页面实际显示为准。

付款后留意邮箱中的订单和服务器通知，也可登录账户后台查看服务。不要把支付成功页面与服务器登录信息混为一谈：后者需要通过邮件或服务管理页面查找，并应作为敏感信息保存。

## 付款后：查看信息与使用控制面板

从网站顶部进入 **Client Area**，登录后打开 **My Services**，找到购买的 VPS 并进入服务详情。参考资料指出，这里可以找到服务器 IP、SSH 端口及进入 KiwiVM 的按钮；订单邮件也可能包含 IP、root 密码和 SSH 端口。连接服务器时应使用实际提供的端口，不要预先假定它一定是 22。

KiwiVM 用于服务器的基本管理。需要确认服务器状态时，可在面板中进行开启、关闭或重启；检查资源时，可查看 CPU、内存和流量使用情况；需要更改管理凭据时，可以使用修改 root 密码的功能。执行操作前先确认当前管理的是哪一台服务，尤其在账户内有多个套餐时。

面板也提供重装操作系统的功能，参考资料提到 Ubuntu、Debian 和 CentOS 等系统。重装可能影响原有数据，因此先确认需要保留的文件已有可用备份，再核对目标系统和操作提示。参考资料还提到部分 CN2 GIA-E 套餐支持切换机房；迁移前应查看该套餐的具体条件，并先确认数据如何处理，不把免费迁移视为所有套餐的通用权益。

## 常见问题与购买前核对

**流量用完会怎样？** 参考资料称，流量耗尽后 VPS 会暂停，待下个月恢复，也可付费提前重置流量。实际处理方式、重置费用及恢复时间应查看服务商当前规则和账户页面。平时可在控制面板关注用量，避免接近额度时才发现服务可能受影响。

**能否退款？** 参考资料称新账户购买后 30 天内可申请一次全额退款。退款资格和限制可能随条款变化，购买前应阅读服务商当前退款政策；不要把参考资料中的描述当作所有订单都能退款的保证。

**下单前最后看什么？** 除了价格，还要确认产品、付款周期、机房、月流量、邮箱和国家或地区是否正确。若使用优惠码，检查验证后的金额；若准备迁移已有数据，先了解所选服务的条件并准备备份。确认这些信息后，再从[套餐总览](https://bwh81.net/aff.php?aff=59244)或上表中对应的产品入口继续选购。
